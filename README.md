# Daily Routine — Android Starter

Open this folder in Android Studio and let Gradle sync.

This starter includes the basic Compose UI, task creation fields, categories/repeat fields, and notification permission/channel setup.

The full production features still need implementation: Firebase Authentication/Firestore sync, Room persistence, recurring AlarmManager scheduling, persistent actionable notifications, boot rescheduling, voice parsing, calendar, search, editing/deleting/pausing, and full offline sync.

Firebase credentials are intentionally not included.
